# Synthetische Testdateien

Alle Dateien in diesem Ordner sind **erfunden** und dienen nur Tests und Probeläufen.
Lieferanten heißen „… (synthetisch)“, GTINs stammen aus dem internen Bereich 200 (nie im Handel vergeben).
Dateien mit `.synthetisch.` im Namen werden beim Import automatisch als Testdaten markiert und im
Supplier Scout wie Demo-Daten behandelt – nie als echte Einkaufsgrundlage.
